# 首页设计稿

## 1. 设计依据与范围

- 视觉依据：[首页首屏](../01_首页首屏.png)。原图尺寸为 **1440 × 810 px**。背景使用现成资源：[背景.png](../资源/背景.png)。
- 本稿只规定桌面端首屏，不包含手机端布局、报告列表页或查重页内部设计。
- 对应现有项目 `check-web/app/page.tsx`，首页路由为 `/`。页面目前只有占位文案，开发时需按本稿实现。

## 2. 文件与组件安排

本页新建的业务组件统一放在 `check-web/components/home/`。组件名使用 PascalCase，组件样式与组件放在同一目录。页面级布局与背景放在 `app/page.module.css`，不要写进 `app/globals.css`；全局样式继续只保留全站通用内容。

```text
check-web/
├─ app/
│  ├─ page.tsx                     # 首页路由入口，组合页面组件
│  └─ page.module.css              # 全视口尺寸、引用首页背景图
├─ public/
│  └─ home/
│     └─ background.png            # 从 01_首屏/资源/背景.png 复制
└─ components/
   └─ home/
      ├─ HomeHero.tsx              # 标题区与按钮区的整体排布
      ├─ HomeHero.module.css       # 两个区域的位置、间距
      ├─ TypingHeadline.tsx        # 两行标题及逐字动画
      ├─ TypingHeadline.module.css # 字体、行高、光标与闪烁动画
      ├─ HomeActions.tsx           # 两个胶囊按钮及行为
      └─ HomeActions.module.css    # 按钮尺寸、间距、颜色、焦点态
```

### 组件职责

| 组件 | 放置位置 | 包含什么 | 不负责什么 |
| --- | --- | --- | --- |
| 首页路由 | `app/page.tsx` | `<main>` 页面容器，渲染 `HomeHero`；引入 `page.module.css` | 不在这里写打字计时器或按钮内部样式 |
| `HomeHero` | `components/home/HomeHero.tsx` | 渲染 `TypingHeadline` 和 `HomeActions`，确定标题区与操作区的相对位置 | 不处理文字动画和路由跳转 |
| `TypingHeadline` | `components/home/TypingHeadline.tsx` | 固定两行文案、逐字显示状态、跟随文字的光标、完成后闪烁 | 不处理按钮 |
| `HomeActions` | `components/home/HomeActions.tsx` | “前往查重”链接和“现有报告”展示元素；保留报告功能扩展注释 | 不创建报告页面或假数据 |

组件导入使用项目已配置的 `@/components/home/...` 别名。`TypingHeadline` 需要客户端状态与定时器，在文件顶部标记 `"use client"`；其余组件如果没有客户端逻辑，保持普通组件即可。

### 页面组合关系

```text
app/page.tsx
└─ <main className={styles.homePage}>
   └─ <HomeHero>
      ├─ <TypingHeadline />
      └─ <HomeActions />
         ├─ <Link href="/check">前往查重</Link>
         └─ <span>现有报告</span>  # 当前只展示
```

`HomeHero` 用普通容器组合子组件，不需要对外开放可配置文案。两行标题和两个按钮都是本页确定内容，直接由各自组件维护即可。
## 3. 页面目标

用户进入首页后，直接看到主题文案，并可通过主按钮进入查重提交页。页面保持简洁，不添加截图中没有的导航栏、说明文字、卡片或页脚。

## 4. 页面结构与文案

页面为全视口首屏，内容水平居中，分为标题区和操作区。

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 标题第一行 | 我没有抄 | 黑色粗体，居中 |
| 标题第二行 | 只是在致敬 | 黑色粗体，居中；末尾显示打字光标 |
| 左侧主按钮 | 前往查重 | 点击进入 `/check` |
| 右侧按钮 | 现有报告 | 当前仅展示，不跳转、不打开弹窗；后续扩展报告页面 |

标题文案中的两行换行是固定的，不依赖浏览器自动折行。不要把设计图末尾的竖线作为文案字符，它是动画光标。

## 5. 桌面布局与视觉

以下位置按 1440 × 810 px 参考图描述，数值是视觉还原参考；以居中关系和整体比例为优先。

- **背景**：直接使用 `01_首屏/资源/背景.png`。开发时复制到项目的 `public/home/background.png`，由 `app/page.module.css` 写 `background-image: url('/home/background.png')` 引用，设置 `background-size: cover` 和 `background-position: center`，覆盖整个视口。
- **标题区**：位于页面上半部中央。第一行大致从 y=125 px 开始，第二行大致从 y=255 px 开始。两行均水平居中，使用黑色、极粗的中文无衬线字形。参考字号约 100–110 px，行高约 1.15。第二行末尾紧跟一根细黑色竖线光标。
- **操作区**：位于页面下半部，两个按钮并排、整体水平居中。参考图中按钮顶部约 y=547 px，尺寸各约 252 × 92 px，间距约 24 px。按钮为黑色胶囊形，文字白色、粗体、约 30 px，文字垂直和水平居中。
- 标题区与按钮区之间保留明显留白。两组元素不使用包裹卡片或额外背景层。
- 本阶段按桌面图实现。桌面窗口宽度变化时，保持标题和按钮组居中，不应出现横向滚动或文字被裁切。

### 样式归属

- `app/page.module.css`：`main` 的 `min-height: 100vh`、宽度、`/home/background.png` 背景引用与溢出控制。不修改根布局 `app/layout.tsx` 来实现首页专属背景。
- `HomeHero.module.css`：内容容器的水平居中、标题区顶部位置、标题与按钮之间的垂直距离。按参考图确定桌面布局，不依靠大量绝对定位逐个摆放字符或按钮。
- `TypingHeadline.module.css`：标题字号、字重、两行行高、居中方式、光标宽度及闪烁关键帧。两行各占稳定高度，避免打字过程中按钮上下跳动。
- `HomeActions.module.css`：双按钮横向排列、按钮宽高、圆角、字体、间距、悬停和焦点态。两个按钮共用同一视觉类。

## 6. 标题打字效果

1. 页面初次显示时，标题从第一个字“我”开始，按阅读顺序逐字出现，直到第二行最后一个字“敬”。第一行完成后再继续第二行，换行位置始终固定。
2. 打字过程中，光标紧跟当前已显示文字的末尾；进入第二行后跟随第二行文字。
3. 全部文字打完后，内容**一直保留**，不删除、不清空、不重新播放。光标停在“敬”字后持续闪烁。
4. 动画只在本次页面加载时播放一次；重新加载页面可以重新播放。打字速度应均匀、易读，建议约每字 100–150 ms，具体可在视觉还原时微调。
5. 文字应保持真实文本，避免用逐帧图片代替。对偏好减少动态效果的用户，可直接显示完整标题和静止光标。

`TypingHeadline` 的实现顺序建议：保存一个已显示字符数，从 0 增至全文总字符数；按第一行长度把已显示内容分配到两行；光标渲染在当前行最后一个可见字符后。计时器达到总字符数后停止，只保留光标的 CSS 闪烁动画。组件卸载时清理计时器。不要用两个独立计时器分别播放两行，以免出现同时打字或顺序错乱。

## 7. 按钮行为

### 前往查重

- 点击后进入现有 `/check` 路由。
- 使用真正可交互的链接或按钮，支持键盘聚焦与 Enter 激活。
- 保持截图中的黑底白字外观；鼠标悬停、键盘聚焦时应有可识别的反馈，但不要改变按钮文案和总体尺寸。

### 现有报告

- 当前版本**仅作静态展示**，点击后不执行操作，也不进入任何页面。不要临时指向空路由或个人信息页。
- 请在对应代码旁写清晰注释，说明此按钮预留给后续“现有报告/报告列表”功能，届时再接入路由和数据。
- 当前不应让用户误以为已存在可用的报告功能。实现时可使用不可交互的展示元素，同时保持截图中的按钮视觉。
- 扩展注释放在 `HomeActions.tsx` 的“现有报告”元素旁，示例：`TODO: 报告列表页完成后，将此展示元素改为指向报告页的链接，并接入对应权限/数据逻辑。`

## 8. 开发顺序与交付验收

建议先建 `components/home/` 下的三个组件及样式，再由 `app/page.tsx` 组合；最后对照截图检查布局、动画和路由。每个组件都应能从上述路径直接定位，不把所有实现集中在 `page.tsx`。

- 在 1440 × 810 px 桌面视口下，背景使用提供的 `背景.png`，两行标题和双按钮的位置、比例与参考图接近。
- 标题从“我”逐字打到“敬”，跨两行连续播放一次；结束后文字不消失，末尾光标持续闪烁。
- “前往查重”进入 `/check`；“现有报告”当前无跳转、无弹窗，代码留有后续扩展注释。
- 页面无截图以外的可见模块，且桌面窗口调整宽度后没有横向溢出。
